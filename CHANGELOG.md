# Changelog

Semua perubahan penting dalam proyek ini akan didokumentasikan di file ini.

Format berdasarkan [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
dan proyek ini mengikuti [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-01

### Added
- ✨ Mode interaktif dengan menu pilihan pola
- ✨ 11+ pola grafis bintang yang berbeda:
  - Pyramid (piramida bertingkat)
  - Diamond (bentuk berlian)
  - Rectangle (persegi panjang dengan border)
  - Wave (pola gelombang sinusoidal)
  - Heart (bentuk hati)
  - Spiral (spiral yang mengisi grid)
  - Galaxy (konstelasi galaksi)
  - Checkerboard (papan catur)
  - Hourglass (jam pasir)
  - Animated Wave (gelombang animasi)
- ✨ Mode demo otomatis dengan 8 pola animasi
- 📁 File konfigurasi JSON (config.json)
- 📖 Dokumentasi lengkap (README.md)
- 🎮 Interface user-friendly dengan validasi input
- 🛡️ Error handling yang robust
- ⚡ Performa optimal dengan delay yang dapat dikonfigurasi

### Features
- Interactive menu dengan 11 pilihan pola
- Auto-play demo dengan animasi smooth
- Real-time wave animation
- Spiral generation algorithm
- Cascading effects
- Pulsing heart animation
- Matrix rain effect
- Customizable delays dan sizing

### Technical
- Kompatibel Python 3.6+
- Tidak ada dependensi eksternal
- Cross-platform support (Windows/macOS/Linux)
- Unicode character support (★)
- Mathematical patterns (sin/cos untuk wave effects)

### Documentation
- README.md dengan panduan lengkap
- Inline code comments
- Usage examples
- Troubleshooting guide
- Extensibility guidelines
